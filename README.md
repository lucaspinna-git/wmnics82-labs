# Netcom Training — Cohort WMNICS82 Interactive Labs

Live Interactive Simulation Labs and Practice Sandboxes for Netcom Training IT Support Course (Cohort WMNICS82).

## 🚀 Live Site
All interactive labs and sandboxes are hosted on GitHub Pages:
**[https://lucaspinna-git.github.io/wmnics82-labs/](https://lucaspinna-git.github.io/wmnics82-labs/)**

## 📚 Structure
- `index.html`: Portal landing hub linking all cohort simulation exercises.
- `unit1/` (or root): Standalone interactive HTML/CSS/JavaScript labs for CompTIA Tech+, A+ Core 1, A+ Core 2, and Business Processes.

## 💻 Technical Notes
Each lab is built as a self-contained web application running entirely client-side, enabling full JavaScript interactivity, drag-and-drop diagnostic mechanics, and real-time feedback without backend dependencies.
