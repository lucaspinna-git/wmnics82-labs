Topic 7.1 • Data Measurements, Storage & Network Throughput

7.1 Units of Speed & Capacity

Every digital interaction boils down to electrical switches and microscopic charge states. Understanding the fundamental distinction between data at rest (storage capacity in Bytes) and data in transit (transmission throughput in bits per second) is the first core competency of an IT support technician.

💾 Storage State Persistent & Volatile

Data at Rest (Storage Capacity)

Data that is housed statically on physical or solid-state media when not actively travelling across a network. This includes operating systems, application software, user documents, and database archives.

Measurement Base: Byte (B) • Upper-case 'B'
Multipliers: KB, MB, GB, TB, PB, EB, ZB, YB
Typical Hardware: NVMe SSDs, SATA HDDs, RAM, USB Flash
Technician Role: Sizing replacement drives, checking partition free space, provisioning system RAM, and planning data retention backups.
🌐 Transmission State Dynamic & In-Motion

Data in Transit (Throughput & Bandwidth)

Data that is actively travelling across an electrical, optical, wireless, or motherboard bus connection. This includes network file downloads, VoIP calls, web streaming, and peripheral bus transfers.

Measurement Base: Bit per second (bps) • Lower-case 'b'
Multipliers: Kbps, Mbps, Gbps, Tbps, Pbps
Typical Channels: Cat6 Ethernet, Fibre Optic, Wi-Fi 6, PCIe Bus
Technician Role: Benchmarking broadband lines, diagnosing network bottlenecks, resolving slow download tickets, and selecting high-speed cables.

🧱 The Three Fundamental Building Blocks of Digital Information

Before evaluating large multi-terabyte arrays or gigabit network connections, every apprentice must master the three foundational units of binary data:

1. The Bit (b) 1 Binary State
0 or 1

The smallest possible unit of computing. Represents a single electrical switch state: off (0) or on (1). Used to measure communication throughput.

Example: A single flag in a database (e.g. Active = 1, Disabled = 0).
2. The Nibble 4 Bits
Half a Byte

A group of exactly 4 bits. A nibble can represent 16 unique values (0 to 15), which maps exactly to a single hexadecimal digit (0 through F).

Example: Hex character F in binary is 1111.
3. The Byte (B) 8 Bits
8 Bits = 1 Character

A collection of exactly 8 bits (or two nibbles). It is the smallest addressable storage unit in memory and can represent 256 distinct characters.

Example: The letter 'A' in ASCII is 01000001.

The Hard Drive Capacity Mystery: Why a 1 TB SSD Reports 931 GB in Windows

Junior technicians frequently encounter tickets from users asking: "I purchased a 1 TB solid-state drive, but when I open File Explorer in Windows, it only shows 931 GB of capacity! Is 69 GB missing or damaged?"

The drive is 100% complete and healthy. The apparent difference arises because hardware manufacturers use decimal (Base-10), whereas operating systems like Windows calculate capacity in binary (Base-2):

1. Drive Manufacturer (Decimal / Base-10):
1 TB = 1,000 × 1,000 × 1,000 × 1,000 bytes
= Exactly 1,000,000,000,000 bytes.
2. Windows Operating System (Binary / Base-2):
1 TiB = 1,024 × 1,024 × 1,024 × 1,024 bytes
= Exactly 1,099,511,627,776 bytes.

Data in Transit • Network Throughput

Full Measurement Hierarchy for Data in Transit

Bits per Second (bps) • CompTIA Tech+ Objective 1.3

Data in transit measures how quickly electronic pulses or light waves travel across transmission channels. While storage capacity is measured in 8-bit Bytes, network throughput is universally measured in single bits per second (bps) using standard decimal multipliers.

1. Bandwidth

The theoretical maximum data-carrying capacity of a link. Think of it as the width of a motorway (e.g. 4 lanes).

2. Throughput

The actual volume of data successfully delivered end-to-end per second. Think of it as the actual cars crossing the bridge per minute.

3. Latency (Ping)

The round-trip delay time taken for a data packet to travel from sender to destination and back. Measured in milliseconds (ms).

The 8-to-1 Rule: Network Bandwidth (Mbps) vs Operating System Download Speed (MB/s)

The single most frequent misunderstanding among computer users is the difference between their advertised internet speed and their file download rate. Because there are 8 bits in every byte, you must divide the network connection speed by 8 to calculate the true file download rate.

Network Throughput (Mbps) ÷ 8 = File Download Rate (MB/s)
100 Mbps ÷ 8 = 12.5 MB/s

Processing Speed • Clock Frequencies

CPU Processing Speed & Clock Cycles (Hertz)

CompTIA Tech+ Objective 1.3 • Hertz Frequency Multipliers

A processor's execution pace is governed by an internal quartz crystal clock generator. The clock produces electrical voltage pulses at fixed intervals. Each pulse is called a clock cycle. During each cycle, the CPU performs microscopic electrical switching instructions.

Base Unit 1 Hertz (Hz) 1 clock cycle per second. Analogous to clapping once every second.
One Thousand 1 Kilohertz (KHz) 1,000 cycles per second. Audio frequencies and low-power microcontrollers.
One Million 1 Megahertz (MHz) 1,000,000 cycles per second. System bus clocks, legacy 1990s CPUs (e.g. 66 MHz Pentium).
One Billion 1 Gigahertz (GHz) 1,000,000,000 cycles per second. Modern desktop & server processors (2.5 GHz – 5.7 GHz).
⚠️ Technician Note on Overclocking & Thermal Throttling

Configuring a processor to operate at a higher clock frequency than its manufacturer specification is known as overclocking. While overclocking delivers more computation cycles per second, it dramatically increases electrical power consumption and heat output.

If the CPU heatsink cannot dissipate this heat fast enough (temperatures exceeding ~95°C–100°C), modern processors automatically activate thermal throttling — lowering their clock speed to protect the silicon from permanent overheating damage.

Topic 7.2 • Internal Architecture & System Integration

7.2 What's Inside a Computer? (Component Architectures)

The computer chassis houses a tightly synchronised ecosystem of silicon, copper buses, and electrical regulators. Study the core internal architectures below—including motherboard form factors, BIOS/UEFI firmware, volatile RAM generations, multicore CPUs, graphics processors, and power supply units—before applying these concepts on the vocational motherboard test bench and PC assembly simulator.

Form Factors Dimensions

ATX vs Micro-ATX vs Mini-ITX

Motherboard size governs case compatibility and expansion slots:

  • • Standard ATX: 305 × 244 mm (Up to 7 expansion slots).
  • • Micro-ATX (mATX): 244 × 244 mm (Up to 4 expansion slots).
  • • Mini-ITX: 170 × 170 mm (Compact small form factor; 1 PCIe slot).
System Firmware POST & Boot

Legacy BIOS vs Modern UEFI

Firmware performs the Power-On Self-Test (POST) and initialises hardware:

  • • Legacy BIOS: 16-bit, keyboard only, MBR partition limit of 2 TB.
  • • Modern UEFI: 64-bit, mouse GUI support, GPT drives > 2 TB, and Secure Boot (blocks rootkits).
System Memory DDR4 / DDR5

Volatile RAM vs Storage

Random Access Memory (RAM) holds active programs and files in use:

  • • Volatile: Requires constant power; contents wipe immediately when powered off.
  • • Dual-Channel: Installing matched pairs in alternating slots (Slots 2 & 4) doubles memory bandwidth to 128-bit.
Processor Cores & Cache

Cores, Threads & Cache

Modern processors pack multiple physical execution engines (cores):

  • • Multithreading: Allows 1 core to execute 2 logical threads (e.g. 8 cores / 16 threads).
  • • L1, L2, L3 Cache: High-speed SRAM built directly onto the silicon to feed data instantly.
Display & Compute iGPU vs dGPU

Integrated vs Dedicated Graphics

Handles visual rendering and parallel computation:

  • • Integrated (iGPU): Built into the CPU, shares regular system RAM.
  • • Dedicated (dGPU): Separate PCIe card with its own dedicated high-speed VRAM and fans.
Power Delivery 80 Plus Rating

Power Supply Unit (PSU)

Converts 230V AC mains electricity into clean +12V, +5V, and +3.3V DC:

  • • 80 Plus Certification: Guarantees ≥ 80% efficiency (Bronze, Gold, Platinum).
  • • Modular Cabling: Unused cables can be disconnected to maximise case airflow.
Processor Architecture • Deep Dive

CPU Types & Specifications: AMD vs Intel Comparison

CompTIA Tech+ Objectives 1.3 & 2.1 • Cores, Threads, Clock Speeds & TDP
🎛️ Physical Cores

An independent, physical silicon execution unit inside the CPU. Each core reads, decodes, and executes computational instructions on its own.

Why it matters: More cores allow the PC to run multiple heavy applications simultaneously without stuttering.
⚡ Logical Threads

A virtual execution sequence handled by a core. Simultaneous multithreading (Intel Hyper-Threading or AMD SMT) splits 1 physical core into 2 logical worker lanes.

Why it matters: Doubling thread count keeps execution pipelines fed with data while waiting on system RAM.
⏱️ Clock Speed (GHz)

The frequency at which the CPU executes cycles, measured in Gigahertz (GHz) (billions of electrical cycles per second). Displays both a Base Clock and a turbo Boost Clock.

Why it matters: Higher clock speed delivers snappier performance in single-threaded tasks and gaming.
🔋 Wattage / TDP

Thermal Design Power (TDP), rated in Watts (W). Represents the maximum electrical energy consumed and heat generated that the computer cooling system must dissipate.

Why it matters: Determines the minimum cooler capacity and Power Supply Unit (PSU) wattage needed.

⚡ Architectural Philosophy: Hybrid vs Homogeneous

Intel uses a hybrid design (big Performance P-cores for main tasks + smaller Efficient E-cores for background tasks). AMD uses homogeneous chiplets where all Zen cores share identical high-performance architectures, often packing massive 3D V-Cache on specialized models.

🔧 Workshop Rule: Sockets Are Platform-Locked

You cannot install an AMD CPU into an Intel motherboard, or vice-versa. Intel currently uses LGA1700 / LGA1851 (pins on the board), while modern AMD uses AM5 (Land Grid Array pins on the board) and legacy AM4 used PGA (pins on the processor).

Each generation increases transfer speeds, expands memory density (module capacity), and reduces operating voltage for superior energy efficiency. Because physical keying notches differ between generations, DDR modules are not backwards-compatible with older motherboard slots.

1. Physical Notch Safety

Memory notches are deliberately placed in unique positions for every DDR generation. If a RAM module does not slide smoothly into the motherboard slot, never force it — forcing will crack the slot or fry the pins.

2. Dual-Channel Installation

When installing two memory sticks on a 4-slot motherboard, always insert them into alternate priority slots (Slots 2 & 4, or DIMM_A2 and DIMM_B2) to double memory bus throughput from 64-bit to 128-bit.

3. Desktop vs Laptop Form Factor

Desktops use full-length 288-pin DIMMs (~133 mm). Laptops and compact SFF systems use 260-pin (DDR4) or 262-pin (DDR5) Small Outline DIMMs (SO-DIMMs, ~67 mm). They are electrically similar but physically incompatible.

🌐

Enterprise Storage Topologies: DAS, NAS, SAN & Cloud

In enterprise businesses, data rarely lives on an individual computer's internal drive. Explore the 4 enterprise storage tiers:

DAS

Direct-Attached Storage

Storage physically plugged straight into the machine via SATA, USB, or Thunderbolt (e.g. external backup drive or internal SSD). Fast, but accessible only by that single host.

NAS

Network-Attached Storage

A dedicated storage appliance connected directly to the office local area network (LAN). Shares folders at the file level using SMB (Windows) or NFS (Linux) protocols.

SAN

Storage Area Network

A dedicated, high-speed secondary network (Fibre Channel or 10Gb iSCSI) interconnecting data centre servers to high-capacity disk arrays. Operates at the block level for virtualisation.

Cloud

Cloud Storage Fabric

Offsite data hosted in multi-tenant data centres (Microsoft OneDrive, SharePoint, AWS S3). Provides global accessibility, automated versioning, and offsite disaster protection.

The Interface vs Mechanical Bottleneck: Bus Bandwidth vs Real Platter Throughput

CompTIA Tech+ Domain 3.2 • Hardware Engineering Analysis
🔍 The Common Technician Confusion: "Why is my 6 Gbps SATA drive only transferring at 150 MB/s?"

Junior technicians frequently see a mechanical hard drive labelled "SATA 6 Gbps" and assume files will transfer at 600 Megabytes per second. In reality, the SATA cable and motherboard controller provide a wide motorway, but the physical spinning disc inside the drive acts as a severe mechanical bottleneck!

2. Why Mechanical Platters Cannot Fill the SATA 6 Gbps Pipe

⏳ Rotational Latency

Data is stored in magnetic circular tracks. When the computer requests a sector, the read head must hover and physically wait for the spinning platter to rotate the exact requested sector underneath the head. At 7,200 RPM, this takes an average of 4.16 milliseconds of dead waiting time.

🧭 Head Seek Time

The read/write heads are mounted on a mechanical actuator arm. Moving this physical arm inward or outward across the disk surface takes 4 to 10 milliseconds. While the arm is travelling, zero data can be read or written to the SATA cable.

📉 The 4K Random Read Collapse

Reading one large continuous file (sequential) is fast (~180 MB/s). But booting an operating system requires reading thousands of tiny 4 KB files scattered across different sectors. Because the head must seek and wait for every file, actual throughput collapses to under 2 MB/s!

3. Architectural Evolution: How Solid-State Drives Solved the Bottleneck

3.5" Mechanical HDD (7,200 RPM) SATA III 6 Gbps (~600 MB/s) ~150–220 MB/s ~12.0 ms (Mechanical) Spinning Platter & Seek Arm
2.5" Solid-State Drive (SATA SSD) SATA III 6 Gbps (~600 MB/s) ~520–560 MB/s ~0.05 ms (Electronic) SATA Bus Limit (Hits ceiling)
M.2 NVMe SSD (PCIe 4.0 x4) PCIe 4.0 x4 Direct 64 Gbps (~8,000 MB/s) ~7,000–7,500 MB/s ~0.02 ms (Electronic) NAND Flash Controller Limits
M.2 NVMe SSD (PCIe 5.0 x4) PCIe 5.0 x4 Direct 128 Gbps (~16,000 MB/s) ~12,000–14,500 MB/s ~0.01 ms (Electronic) Thermal Throttling (Requires heatsink)
💡 Key Vocational Takeaway for Apprentices: When upgrading older client computers, swapping an old 5,400 RPM mechanical laptop drive for even a cheap SATA SSD delivers a dramatic 500% to 1,000% speed increase in real-world application launch and boot times. It is not just about the peak megabytes per second: eliminating the 15 ms mechanical seek latency transforms system responsiveness!

CompTIA Tech+ Standard Hardware Troubleshooting Codes

🔍 Self-Directed Troubleshooting
When a computer fails to boot (fails POST), the system communicates through Audio Beep Codes and Motherboard Q-LEDs. Use the lookup tables below to identify the faulty subsystem and determine the technical root cause.

LED Indicator Colour Associated Subsystem & Fault Condition

VGA LED Solid White No display output detected. Occurs if CPU lacks integrated graphics and no dedicated graphics card is fitted.

Beep Pattern POST Diagnosis Required Technician Action

3. Processor Socket & Graphics Architecture

Intel Core Ecosystem (LGA1700):

Uses the Land Grid Array (LGA1700) socket where pins reside on the motherboard. Intel desktop processors typically feature built-in Integrated Graphics (e.g. Intel UHD), enabling video output without requiring a separate graphics card.

AMD Ryzen Ecosystem (AM5 & AM4):

Modern AMD AM5/AM4 performance processors generally require a dedicated graphics card installed into a PCIe x16 slot to generate video signal for a monitor, as highlighted in CompTIA Tech+ Section 7.2.5.

4. Power Budget & Headroom Formula

To prevent abrupt shutdowns during peak processing loads, IT technicians calculate system power using the following standard rule:

Total System Draw = CPU Watts + GPU Watts + Motherboard Base (~50W)

Rule of Thumb: The Power Supply Unit (PSU) should provide at least 20% to 25% safety headroom above the calculated system draw.

5. Benchmark Scores & Workload Tiers

Tier 1: Entry Office & Web Admin (< 5,000 pts)
Budget quad-core, integrated graphics, 8–16 GB RAM. Low power consumption (< 200W). Ideal for word processing, email, and web apps.
Tier 2: Mainstream Business & Multi-Tasking (5,000 – 12,000 pts)
6–10 Core CPU, 16–32 GB DDR5 RAM, high-speed NVMe storage. Handles complex spreadsheets, multi-monitor displays, and local databases.
Tier 3: Engineering, CAD & Content Creation (12,000 – 22,000 pts)
High-clocked CPU, 32 GB+ RAM, dedicated PCIe GPU (RTX 4060 / RX 7600 XT). Designed for 3D drafting, video encoding, and graphical simulations.
Tier 4: Enterprise Heavy Compute & 3D Simulation (> 22,000 pts)
Flagship CPU (i9 / 7800X3D), 64 GB RAM, enthusiast GPU (RTX 4080 / 4090), PCIe Gen 5 NVMe. Extreme processing power requiring 750W–1000W+ PSUs.

6. Workshop Safety: Prohibition on Hot-Plugging

⚡ Catastrophic Short-Circuit & Arc Warning

Internal computer components (CPU, Motherboard, RAM, PCIe Cards, SATA/M.2 Storage, and internal power headers) are not hot-swappable.

Attempting to insert or extract internal hardware while the computer is connected to electrical power will cause instantaneous electrical arcing, short-circuit the motherboard power delivery planes (12V / 5V / 3.3V rails), blow surface-mount capacitors, and trigger permanent silicon destruction.

Technician Rule: ALWAYS shut down the system and disconnect the mains power supply cable before opening or servicing the computer chassis.

A reversible connector capable of carrying up to 40 Gbps data, DisplayPort video (Alt-Mode), and up to 100W–240W of Power Delivery (PD) through a single corporate laptop dock.

The classic non-reversible USB connector. USB 3.0 ports feature a bright blue or teal internal plastic tongue to signify SuperSpeed 5 Gbps – 10 Gbps throughput.

RJ-45 Ethernet Jack

Terminates unshielded twisted pair (UTP) network cabling (Cat5e, Cat6, Cat6a). Features an audible retention click clip and dual status LEDs (Link & Activity).

Analogue Video Only 15-Pin D-Sub

VGA (Video Graphics Array)

Legacy 15-pin analogue blue connector with two thumbscrews. Does not transmit audio; prone to signal degradation over long cable runs. Deprecated by modern standards.

Topic 7.5 • Plug and Play Architecture & Hardware Diagnostics

7.5 Installing Connected Devices & Diagnostics

When you insert a peripheral into a computer, a sequence of automated hardware identification, driver installation, and resource allocation takes place. Master the Windows Device Manager to diagnose and fix hardware faults.

Automated Discovery

How Plug and Play (PnP) Works

Plug and Play allows an operating system to adapt to hardware changes without requiring manual jumper configuration or computer reboots:

  1. Bus Detection: Motherboard detects an electrical connection on USB, PCIe, or Thunderbolt.
  2. Hardware ID Query: OS reads the Vendor ID (VEN_) and Device ID (DEV_).
  3. Driver Store Search: Windows queries its local driver repository (System32\DriverStore) or Windows Update.
  4. Resource Allocation: The OS assigns Memory Addresses, Interrupt Requests (IRQ), and I/O channels.
Driver Software

Generic In-Box vs Vendor OEM Drivers

A driver is the specialised translation layer connecting the OS kernel to physical silicon:

Generic Windows In-Box Drivers: Basic functionality (e.g. generic display adapter, standard 2-button mouse). Enables basic system operation out-of-the-box, but lacks advanced hardware acceleration.
Vendor OEM WHQL Certified Drivers: Written by the hardware creator (NVIDIA, Realtek, Intel, HP). Unlocks full performance, custom colour profiles, multi-monitor controls, and verified by Microsoft WHQL testing.
